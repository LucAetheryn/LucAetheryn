# Reference analysis — Hiroyki repository ZIP

This package takes structural inspiration from the uploaded `hiroyki-main.zip`, while all Stellar Universe artwork and copy are original.

Observed reference structure:
- `README.md` uses `<picture>` with separate desktop/mobile assets.
- `assets/` includes header, desk, divider, footer, city, timeline, marquee, stack, AI orbit, section title graphics, social icons, and project cards.
- `assets/m/` contains mobile-specific variants.
- `profile-summary-card-output/` stores generated summary card SVGs.
- `.github/workflows/` includes contribution graph, guestbook, and summary card workflows.
- `.github/ISSUE_TEMPLATE/guestbook.yml` defines the guestbook form.
- `.github/scripts/guestbook.js` updates the README guestbook section.

Adaptations in this package:
- Stellar Universe has original cosmic palette, copy, project cards, timeline, and SVG artwork.
- A mobile asset directory and `<picture>` layout are retained.
- Snake, summary-card, and guestbook automations are included.
- Personal contact details and project repository links are intentionally not fabricated.
